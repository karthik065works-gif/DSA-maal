# 🧩 Problem-Solving Approach

For every problem, I aim to follow a structured approach:

```text
1. Understand the problem
        ↓
2. Identify constraints
        ↓
3. Develop brute-force solution
        ↓
4. Analyze time & space complexity
        ↓
5. Identify optimization opportunities
        ↓
6. Develop optimal solution
        ↓
7. Implement
        ↓
8. Test edge cases
        ↓
9. Analyze complexity
        ↓
10. Document the approach
```

The objective is to understand **why a solution works**, rather than simply memorizing code.

# 💡 Brute Force → Optimal Thinking

One of the main objectives of this repository is to develop the ability to transform inefficient solutions into optimized ones.

### Example

**Problem: Longest Subarray with Sum K**

### Brute Force

```text
Generate every possible subarray
        ↓
Calculate its sum
        ↓
Check whether sum == K
```

Complexity:

```text
Time:  O(N²)
Space: O(1)
```

### Optimized Approach

```text
Prefix Sum
     +
HashMap
```

Complexity:

```text
Time:  O(N)
Space: O(N)
```

The focus is on understanding the **pattern behind the optimization**, not just the final implementation.
